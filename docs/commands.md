# 可复制指令库

上传相应素材后复制。文字中的“第一张／第二张”必须符合你实际上传顺序。

## 01．给三个TVC方向

~~~text
使用 $product-storytelling-studio。

第一张是商品，第二张是模特。
给我3个不同方向的TVC广告短视频脚本。
每个3幕，每幕8秒、2镜，9:16。
带货段亢奋高能；人物、背景、皮肤全部Realistic。
故事要有因果、有反差、紧凑，动作符合物理。
马来西亚马来语对白。
每条最后附有Hook的TikTok Caption。
先只给脚本。
~~~

## 02．选定故事，先出图

~~~text
使用 $product-storytelling-studio。

采用刚才的第2个故事。
模式：Cinematic
视觉：iPhone / Editorial Realism
类型：Commercial / TVC
节奏：开头尽早出事件，中段反差，结尾留反应。
语气：亢奋／高能兴奋，保留故事需要的情绪铺垫。
皮肤：Realistic
灯光：Natural Light
3幕，每幕8秒、2镜，9:16。
马来西亚马来语对白。
保留商品原色、结构、图案及模特外观。
先生成每幕首帧图，再给各幕英文视频提示词。
最后附TikTok Caption。
~~~

## 03．王家卫电影观感

~~~text

模式：Cinematic
视觉：写实人物、写实背景。

构图：前景遮挡、门框取景、亲密近景。
灯光：局部暖冷光对照，中性补光保留商品原色。
节奏：紧凑，停顿有作用，不拍成漫长摆拍。
3幕，每幕8秒、2镜，9:16。
先给Story和分镜。
~~~

## 04．已上传首帧，写Omni提示词

~~~text
使用 $product-storytelling-studio。

这次只上传了一张已合成人物和商品的首帧。
为Omni写一份可直接粘贴的英文视频提示词。
计划8秒、2镜。
动作：人物站起，左手握住旁边包的短提把，提到左侧。
人物只说：“Jom!”
保留首帧里的脸、服装、背景和光线。
说明真实动作顺序，不引用未上传的Image 2。
只要提示词，不生成视频。
~~~

## 05．首尾帧过渡

~~~text
使用 $product-storytelling-studio。

第一张是首帧，第二张是尾帧。
先检查人物、服装、机位和空间是否能连贯连接。
写自然转身与步伐，让动作从首帧过渡到尾帧。
计划8秒。保留商品原色和结构。
只给英文视频提示词。
~~~


## 08．改语气

~~~text
保留目前故事、人物、商品与场景。
语气改成亢奋／高能兴奋，强情绪。
措辞、重音、表情和手势都体现兴奋，但保留换气和展示时间。
原本疲惫的铺垫段仍然疲惫。
~~~

## 09．修正说话人

~~~text
第二幕的画外声被主角说出来了。
保留剧情，把本次视频改成只有主角说“Dekat mana?!”
闺蜜的“Jom makan!”单独写成后期画外音安排。
注明邀请和回应的时间、主角闭嘴倾听的区间。
不要声称已生成或混好音。
~~~

## 10．衣服受力

~~~text
人物左手只抓住衣服的一个位置。
没有衣架或第二只手支撑时，其余布料自然下垂并形成褶皱。
修正悬空撑开的形状，保持原色、图案和参考人物外观。
需要展示展开版型时，安排明确的第二处支撑。
~~~

## 11．紧凑版改写

~~~text
保留故事因果，把脚本改得更紧凑。
开头2秒内出现事件或疑问，每幕都推进。
删掉重复台词和无进展停顿。
每幕8秒、2镜，动作仍要有时间完整完成。
~~~

## 12．只要Caption

~~~text
根据这条视频的真实剧情，写3个马来西亚马来语TikTok Caption。
首句有具体Hook，接共鸣和自然互动问题。
每个附3–5个相关标签。
不要编造价格、功效、销量或假稀缺。
~~~

## 13．保持商品原色的电影光线

~~~text
保留当前电影构图与冷暖背景光。
人物和商品增加协调的中性补光，使产品原色可辨。
不要为了电影氛围把深蓝变成黑色或紫色。
只修光线与色彩，保留动作和场景。
~~~

