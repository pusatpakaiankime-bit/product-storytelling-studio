# 创作参数与提示词落实

## 来源与使用方式

完整界面目录见 [option-catalog.json](option-catalog.json)：2026-10-12 从 Studiova Storytelling 高级页读取的 12 组、107 个选项。目录的 label/value 是观察记录，不是接口文档，也不保证模型仍可用。下文映射是本 Skill 独立设计的创作解释，未经逐项媒体对照测试，不得称为网站原版规则。

用户可选目录里的值，也可用自然语言、自定义风格、其他语言或模型；目录不限制能力范围。中文称呼与英文标签可等价匹配，例如“王家卫”“自然光”“原生肤质”“每幕两镜”。有歧义且影响结果才询问。仅需完整菜单时读取 JSON，普通创作按相关章节使用。

## 参数优先级与冲突

- 用户明确的创意和设置优先；自动电影预设只补全未指定项。已确认商品事实及需保留的参考外观不可被风格改写。
- 保留既有默认值：写实、9:16、1 个主要角色、3 幕×8 秒、每幕 1–2 镜。高级项目未指定时按故事选择，不机械继承网站测试项目的 selected 值；目录不记录默认值。
- 本用户明确要求人物、背景及皮肤默认均为 Realistic；人物、商品和场景使用协调的写实摄影，不因为电影观感自动变成动画／三维。带货用途未指定语气时，默认亢奋／高能兴奋、强情绪，按 tone-presets.md 落实；明确的其他风格、语气及故事情绪转折优先。
- 先协调视觉风格→电影观感→具体镜头/灯光/皮肤。明确“自然光”加霓虹电影观感时，可保留构图与明暗层次，使用自然光；不能擅自改成夜间霓虹。商品需要辨色时避免综合色偏覆盖商品。
- 电影风格不强制增加对应 IP 人物、场景或剧情。把用户所选名称翻译为可观察的构图、光线、色调与节奏。
- 比例明确为 9:16 时，Anamorphic Widescreen 可借用光学观感，不自行改成横屏或加黑边。虚化、暗光、强光晕不能遮掉本镜头需要验证的商品细节。
- Long Take 与多镜头：每镜可较长，切镜点仍明确；若用户要求整幕一镜到底，则不能同时编造硬切。对两个同等明确且无法共存的要求说明冲突并澄清；自动补全可自行调整。
- 生成模型的实际能力影响执行方式。不能把“计划 8 秒”写成工具已经支持；需要分段时说明连接和剪辑方案，保持用户总时长目标。

## 12 组参数如何生效

### 1. Visual Style：9 项

| 页面 value | 创作处理 |
|---|---|
| iphone | 生活摄影比例、自然曝光、克制景深，避免默认过度磨皮 |
| cinematic | 有动机的电影布光、层次和有目的的构图 |
| pixar | 三维动画造型、材质与灯光；说明人物为风格化演绎，产品结构仍需辨认 |
| anime | 二维动画线条、绘制背景、受控色块；不承诺真人照片般的相似度 |
| cyberpunk | 科幻城市色彩和实景光源；与明确灯光/商品辨色要求协调 |
| pip_narrator | 画中画讲述者配写实主画面；讲述者位置固定，避开商品 |
| pip_3d_bg | 画中画讲述者配三维动画背景；人物和背景分别描述 |
| pip_anatomy | 画中画讲述者配三维解剖示意；仅在需求相关且信息有依据时使用，不生成虚假健康功效 |
| custom | 将用户自定义风格写成具体视觉约束 |

PiP 需明确主画面与小窗区域。如果生成平台不能稳定完成，提出分层生成后合成；文本方案不宣称已经合成。

### 2. Genre：9 项

General/Free 自由结构；Music Video/Performance 用表演与节拍组织镜头；Horror/Thriller 用信息延迟和环境建立悬念；Action/Fast Paced 用可读动作与因果剪辑；Emotional Drama 用行动和反应；Documentary 用有依据的观察/旁白；Commercial/TVC 围绕商品可见特征与真实诉求；Podcast/Studio Talk 固定谈话布景；Interview/Vox Pop 组织问答与反应。不因类型标签虚构用户证言或商品能力。

### 3–4. Aspect Ratio 与 Language

比例：16:9、9:16、1:1，影响首帧构图、全身/产品留白和可用运动空间。目录语言为 Malay (Malaysia)、English，但用户可选其他语言。中文解释与原对白分开，翻译不混入视频音轨提示词。

### 6. Camera Motion：14 项（混合了运动、机位、景别与对焦）

| value | 写入镜头的实际动作 |
|---|---|
| auto | 为当前动作选择一种清楚机位/运动 |
| fpv | 明确起止位置、飞行路径和障碍净空，商品近景可另设静稳镜头 |
| continuous | 连续拍摄或慢速展示运动；Long Take 与 Glambot 并非同义，按用户偏好明确选哪种 |
| orbit | 主体相对稳定，指定环绕角度与方向；完整 360° 会揭示未见背面，不能假称该部分准确 |
| tracking | 与人物同方向跟随，明确侧/前/后及距离 |
| whip_pan | 快速摇摄连接两个明确目标；有切镜时标明切点 |
| handheld | 小幅自然手持，不让抖动破坏细节或可读性 |
| low_angle | 低机位仰拍，写清产品比例可能受透视影响 |
| birds_eye | 顶视构图，明确桌面/地面物件排列 |
| dutch_tilt | 适量倾斜画面建立张力，不等于镜头持续滚转 |
| over_shoulder | 肩部前景与视线目标，说明肩部属于哪个角色 |
| ecu | 特写可辨认的商品结构或动作，不把局部当全身展示 |
| rack_focus | 明确前景对象→背景对象的对焦转移，机位可保持固定 |
| dolly | 反向变焦与前后移动保持主体画面尺寸，按工具能力作为计划 |

### 7. Lighting：5 项

Auto 按地点与时段决定；Golden Hour 为低角度暖侧/逆光与长阴影；Film Noir 为定向硬光和低调阴影；Natural Light 为窗光或真实户外光；Neon/Cyber 为明确位置的彩色实景灯。保持跨幕时间连续，不因风格自动把早晨改成夜间。

### 8. Skin Texture：3 项

- Realistic：自然皮肤微纹理、适量光泽与真实过渡。
- Soft/TVC：柔光、克制细节与平滑色阶，不自动改变脸型。
- Imperfect/Raw：保留参考已有的纹理与不均匀肤色，减少磨皮；不要凭空加雀斑、伤疤、痘痘、皱纹来证明“真实”。

皮肤参数不锁定身份，不覆盖参考人物特征；无人物场景或非写实材质可标不适用。

### 9–11. Scene Count、Shot Density、Duration

- 幕数目录：1、2、3、4、5、6、8、10、12、15、20；用户可自定义。
- 每幕镜头数：1–10；明确用户是否每幕相同，允许逐幕覆盖。每个镜头写不重叠时间段，总和等于该幕时长。3 幕×8 秒×每幕 2 镜＝24 秒、6 个计划镜头，不是 6 幕，也不自动需要 6 张图。
- 时长目录：Auto/Flexible、4s、6s、8s、10s。菜单所带 Runway/Grok/Veo/Kling/Sora/Luma 名称仅为历史标签，不是最新模型限制。
- 用户指定高密度时给足计划镜头，优先简短动作和明确切点。若目标模型无法稳定执行，标出逐镜生成/剪辑的执行方案，不暗中减少镜头数或额外发起付费调用。
- Auto 时按内容分配实际时长并列明结果。固定总时长与每幕时长冲突时，不把两个不一致的数字同时宣称满足。

### 12. Video Model

历史下拉：Veo 3.1、Seedance 2、Grok Imagine、Kling 1.5、Runway Gen-3。页面单幕按钮另有 Omni，Skill 也接受用户指定 Omni 或其他模型；菜单不是白名单。JSON 中出现的价格/最大时长只是当日原始标签，不嵌入长期默认，不用于计算本次费用。

只写文本时明确“目标模型/计划时长”；实际执行才核对指定平台当前支持的参考图、分辨率、时长、音频、积分与输出。不能用模型名推定后台真实供应商或接口。

## 其他可选控制

- 角色：1C/2C/3C/Ensemble；给每位角色独立参考和镜头职责。不要把只有一张参考脸用于所有人物。
- Main Char：控制是否需要贯穿主角；关闭时仍可有必要的手部/人物，但不要自动添加持续口播主持人。
- Script：是否含口播/旁白；关闭不等于关闭环境声。Music、Ambience/SFX 分别控制配乐和环境/动作声音，用户要求无声时全部关闭。
- Visual Hook：开头设置可见的动作/信息差。Tone 有 24 种本地预设，保留 Natural 自然、Emosi 情绪、Puitis 诗意、Komedi 喜剧；完整名称、表达差异和例句见 [tone-presets.md](tone-presets.md)。语气只影响表达，不改变商品事实；可选一个主语气并用另一个语气轻微修饰，也接受自定义描述。
- Timelapse 与 Continuous：分别是过程压缩和连续运动意图，不能仅凭开关名称承诺网站实现；用户同时选择时可明确连续机位下的时间压缩。
- 对白起点：Awal 从开场、Tengah 视觉铺垫后、Akhir 触发事件后。写具体开始秒数并检查余下时间是否够说完整句，不能将全部对白塞在最后一秒。
- 负面提示词按任务选择。参考词汇：unwanted text, watermark, anatomy errors, product shape/color drift, flickering, unintended morphing, duplicated limbs, teleporting。商品原有 logo 需要保留时不能同时写“no logos”；复古/恐怖等有意效果也不应被通用负面词抵消。

## 完成检查

逐项核对用户显式选择是否进入对应的分镜/首帧/视频提示词；保持商品辨识、人物参考、时间和声音一致。完整交付按 output-contract 的采用参数摘要输出。创作方案审核与媒体实测分开，未经生成不能说已验证模型服从全部参数。
